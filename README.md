# 김준희 (Yeonji-Gonji)

디자인에서 출발한 프론트엔드 개발자입니다.

시각디자인을 전공하고 브랜드 커머스 UI/UX 디자이너로 일하다가 개발로 전향했습니다.
지금은 AI 프로덕트 스타트업에서 프론트엔드 개발과 기획을 함께 하고 있습니다.
화면을 직접 그릴 수 있어서, 디자인과 로직이 같은 언어를 쓰는 제품을 만드는 데 관심이 많습니다.

**포트폴리오 · 블로그 → [yoramilji.kr](https://yoramilji.kr)**

## 하는 일

- React, Next.js, TypeScript 기반 웹 프론트엔드
- 3D 웹(react-three-fiber), 실시간 통신(WebSocket), 결제·인증 등 제품 기능 구현
- UI 설계와 디자인 시스템. 필요하면 Figma로 직접 그리고 코드로 옮깁니다

회사 작업(이러닝 LMS, 전시 부스 3D 웹앱, AI 대화 서비스 등)은 코드 공개가 어려워
[yoramilji.kr/portfolio](https://yoramilji.kr/portfolio)에 케이스로 정리해 두었습니다.
